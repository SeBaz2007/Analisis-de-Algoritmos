Proyecto 1 — Modelo Conjunto

 1. Descripción

Este programa permite trabajar con dos conjuntos, A y B, mediante un menú de opciones. Se pueden insertar, eliminar 
y buscar elementos, mostrar los conjuntos y calcular su unión, intersección y diferencia.

También permite cambiar la estructura de datos utilizada para representar los conjuntos:

1. Lista por punteros: Lista simplemente enlazada.
2. Lista por arreglos: Lista almacenada en un arreglo.
3. Tabla hash: Estructura que permite organizar y buscar elementos mediante una función hash.

 2. Requisitos

- Tener instalado Python 3
- Mantener main.py y los archivos de las tres implementaciones en la misma carpeta:
  - ConjuntoHash.py`
  - ConjuntoListaArreglo.py
  - ConjuntoListaPunteros.py

 3. Cómo ejecutar el programa

Abra una terminal en la carpeta del proyecto y ejecute:

Win/Linux
python3 main.py
